# IA Generativa com Copilot e OpenAI

## Descrição do Projeto
Este projeto demonstra o uso de IA generativa para reconhecimento de texto em imagens. Utilizando GitHub Copilot para sugestões de código e OpenAI para análises avançadas, o objetivo é automatizar o processo de extração e interpretação de texto a partir de imagens, facilitando tarefas que antes exigiam esforço manual.

## Visão Geral
Este projeto explora o uso de IA generativa, utilizando GitHub Copilot e OpenAI para automatizar tarefas de reconhecimento de texto em imagens. A ideia é demonstrar como essas tecnologias podem ser aplicadas para extrair e processar texto de imagens de forma eficiente.

## Estrutura do Repositório
- **inputs/** → Contém as imagens usadas no processo.
- **output/** → Contém os arquivos de texto extraídos das imagens.
- **README.md** → Documentação do projeto.

## Tecnologias Utilizadas
- **Python 3**
- **Tesseract OCR** para reconhecimento de texto
- **GitHub Copilot** para sugestões de código
- **OpenAI** para análise e processamento avançado

## Como Executar
1. Instale as dependências necessárias:
   ```bash
   pip install pytesseract pillow
   ```
2. Execute o script de reconhecimento de texto:
   ```bash
   python script.py
   ```
3. Os arquivos processados estarão na pasta `output/`.
